# Movie Viewer App - Screen Mockups

## 📱 View the Mockups

**Open `screen-mockups.html` in any web browser** to see interactive visual mockups of all 9 screens in the Movie Viewer app.

## 🎬 Screens Included

1. **Login Screen** - User authentication with user ID and password
2. **Registration Screen** - New user signup with camera integration for profile picture
3. **Movie List Screen** - Browse movies with 4 tabs (Popular, Top Rated, Now Playing, Upcoming)
4. **Movie Detail Screen** - Detailed information about a selected movie
5. **Reviews Screen** - Read user reviews for movies
6. **Search Screen** - Search for movies with debounced input
7. **Favorites Screen** - View favorited movies
8. **Profile Screen** - View and edit user profile
9. **Offline Mode** - Shows how the app behaves when offline

## 🎨 Design Features

- **Dark Theme** throughout (Material Design 3)
- **Primary Color:** Blue (#1976D2)
- **Phone Frame:** Realistic device mockup
- **Interactive Layout:** 2-column grid for movies
- **Bottom Navigation:** 4 tabs for main sections
- **Consistent UI:** All screens follow same design language

## 📂 Files

- `screen-mockups.html` - Interactive HTML mockup (open in browser)

## 🚀 How to Use

1. Navigate to the `mockups` folder
2. Double-click `screen-mockups.html`
3. Your default browser will open showing all screen mockups
4. Scroll through to see each screen design
5. View the feature summary at the bottom

## ✨ Key Features Visible

- Material Design 3 components
- Dark theme with consistent colors
- Movie cards with posters, ratings, and info
- Scrollable tabs for category switching
- Profile management interface
- Search functionality
- Favorites management
- Offline mode indicator

## 📱 Responsive Design

The mockups are responsive and will adjust to your browser window size. For best viewing:
- Desktop: Full-width display with multiple screens visible
- Mobile: One screen per row for easier viewing

## 💡 Note

These are visual mockups showing the layout and design of the actual Android app. When the app builds successfully, it will look exactly like these mockups but with:
- Real movie data from TMDB API
- Actual movie posters loaded via Coil
- Working navigation and interactions
- Database persistence with Room
- Camera integration for profile pictures
